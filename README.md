# flights-data

Static data behind [fakeronjan.com/flights](https://fakeronjan.com/flights): US domestic route statistics (on-time rates, airlines, delay causes, trends) built from the Bureau of Transportation Statistics' Marketing Carrier On-Time Performance data, January 2018 on.

Generated by `tools/flights/build_site.py` in the fakeronjan-com repo. Served with GitHub Pages; don't edit by hand.

- `meta.json`: years available, the last-12-months span, build date
- `airports.json`: airport code -> [city, flights in the last 12 months]
- `y/<window>/<ORIGIN>.json`: routes from that airport for a year (or `last12`)
- `y/<window>/rank.json`: every route's flights and on-time count, for rankings
- `trends/<ORIGIN>.json`: each route's yearly totals and airline mix
